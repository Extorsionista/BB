# Akatsuki PS4 14.02 — GitHub Pages dashboard

This folder is a static, mobile-friendly project information dashboard. It is suitable for GitHub Pages.

## Publish with GitHub Pages

1. Create or open your GitHub repository.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## What the live panel means

The clock updates every second. The refresh control updates the dashboard timestamp and confirms that the local interface is responsive. It does not contact a PS4, verify payloads, or report exploit execution progress.

## Project status

The supplied project README describes the 14.02 build as experimental and not hardware-tested. Kernel-stage compatibility and system stability are not guaranteed. Read the original project documentation and understand the risks before using any console modification.
